# Labyrinth Cleaner Mac App Implementation Plan (plan 2 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `Labyrinth Cleaner.app`: a native menu-bar app with a window that shows the existing page. The window is backed by an app-owned Python server, a folder picker bridge and a signed-later trash helper. It is built by `scripts/build_app.sh` as a dev bundle. Embedding Python, Developer ID signing, notarization, the DMG and Sparkle are plan 3.

**Architecture:** A SwiftPM package in `app/` holds three targets:
- `LabyrinthKit`: a Foundation-only library holding all testable logic, including the server process.
- `LabyrinthCleaner`: the AppKit app, kept thin.
- `labyrinth-trash`: the helper that moves Downloads files and Xcode archives to the Trash.

The app runs `python3 devclean ui --app`. That server prints one JSON handshake line, never idles out, and exits when its stdin closes. A WKWebView shows the page. Python stays the single authority on what is deletable. The Swift side only re-checks trash moves, as a second line of defence.

**Tech Stack:** Swift 5 language mode, swift-tools-version 5.9, macOS 13+, AppKit, WebKit, ServiceManagement, UserNotifications, XCTest. The Python 3 stdlib core is unchanged in style.

**Spec:** `docs/superpowers/specs/2026-11-13-labyrinth-cleaner-app-design.md` ("The app", "Constraints", "Left to the builder", "Tests"). Plan 1 (`docs/superpowers/plans/2026-11-13-cleaner-core-and-page.md`) is done on branch `feat/cleaner-core`. This plan runs on `feat/mac-app`, branched from it.

## Global Constraints

- **Never delete for real on the developer's Mac.**
  - Tests use fixture homes only: `tempfile.mkdtemp` plus `os.path.realpath` in Python, `FileManager.temporaryDirectory` in Swift.
  - The built app is launched for checks **only** as a debug build with `--fixture-home <temp dir>`.
  - Nobody presses Delete or Review & clean in a window showing the real home.
- **Tests never call the real** `xcrun`, `docker`, `osascript`, `lsappinfo`, `mdls`, `FileManager.trashItem`, `SMAppService` or the Trash.
- **Python is the authority.** The Swift side never decides what is deletable. The trash helper only re-checks, and it mirrors the core's rules exactly; it is never looser.
- **No `/usr/bin/python3` in what ships.**
  - The app and the CLI launcher use only `Contents/Resources/python/bin/python3`.
  - Dev builds put a shim there that execs `/usr/bin/python3`. Plan 3 replaces it with the embedded interpreter.
  - Python always runs with `-E -s -X utf8`.
- **Names and values:**
  - Bundle ID `com.labyrinth-apps.cleaner`; app name `Labyrinth Cleaner`.
  - Executable `LabyrinthCleaner`; helper `Contents/MacOS/labyrinth-trash`.
  - Minimum macOS 13.0. Window about 1100×800, minimum 900×600.
- **The menu-bar number** is unchanged from DevcleanBar:
  - Finder's "important usage" free space, decimal GB.
  - Amber below 30 GB, red below 15 GB.
  - One notification below 15 GB, re-armed above 20 GB.
  - Refreshed every 60 s and when the menu opens.
- **Nothing runs in the background except that 60 s free-space read.** No scan without the user opening the window, and a login launch never opens the window.
- **Pasteable commands** in user-facing text: no leading `!`, no trailing `# comment`.
- **Suites:**
  - `/usr/bin/python3 -W error::ResourceWarning -m unittest discover -s tests` (250 now, must stay green).
  - `cd app && swift test`.

## Decisions in this plan (builder's calls the spec left open)

1. **The app-owned server never idles out** and exits when the app's pipe to its stdin closes. A crashed app can't leave a server behind.
2. **The handshake** is the first stdout line: `{"labyrinth_server": 1, "url": "http://127.0.0.1:<port>/?t=<token>"}`.
3. **The debug fixture home:** `--fixture-home DIR`, `--simctl-fixture DIR` and `--fake-docker FILE` launch arguments, honoured only in `DEBUG` builds.
4. **The trash helper picks the real Trash or a fixture Trash itself:**
   - It runs as `labyrinth-trash --home H PATH`.
   - If `H` is the real home (from `getpwuid`, resolved), it uses `FileManager.trashItem`.
   - For any other `H`, it moves the item into `H/.Trash`.
   - So a fixture run can never reach the real Trash, whoever calls the helper.
5. **Login launch:** the window opens at launch unless the launch Apple event says "launched as login item" (`keyAEPropData == keyAELaunchedAsLogInItem`). Reopening the app (Dock or Finder double-click) opens the window.
6. **`devclean menubar install` is retired.** It prints a pointer to the app; `uninstall` keeps working. The app warns once if the old `local.devclean.bar` is still running.
7. **The "disk almost full" notification** uses UserNotifications. Permission is asked only the first time a notification is due.
8. **"Check first" rows that would show `NO COST` show `SEE WARNING` instead** (plan 1 parked item).
9. **The project-root check also compares against the resolved protected paths** (plan 1 parked item).
10. **Empty Trash** runs inside `with timeout of 3600 seconds`. The `-1743` (automation denied) and `-1712` (timed out) errors get plain messages.

## Review Focus

1. **The app launched from Finder:**
   - It has a bare `PATH` and cwd `/`, so Docker must still be found and the server must still start.
   - Test: `ServerEnvironment` tests in Task 4. The `ServerProcess` test runs with cwd `/`.
2. **The app quits or crashes in the middle of a clean:**
   - The item being deleted finishes, no further item starts, and no Python process is left behind.
   - Tests: the stdin-EOF tests in Task 2 and the terminate test in Task 4.
3. **A picked folder whose path has `"`, `\`, a newline, U+2028 or `</script>`** must not inject script into the page.
   - Test: `BridgeTests` in Task 5.
4. **A Downloads file swapped for a symlink, or its folder swapped for a symlink, between the scan and the move** must be refused by the helper.
   - Test: `TrashCheckTests` in Task 3.
5. **The app opened again while it is running, or the window reopened,** must not start a second server.
   - Tests: `LSMultipleInstancesProhibited`, plus the "start twice" test in Task 4.

public enum TrashTarget: Equatable { case downloadsFile, archive }
public struct TrashRefusal: Error, Equatable { public let message: String }
/// Mirrors devclean_core's REVIEW rules. lstat (no-follow) on every component below `home`.
public func checkTrashable(path: String, home: String) -> Result<TrashTarget, TrashRefusal>
/// Exit codes: 0 moved, 2 usage, 3 refused (stderr starts "REFUSED: "), 4 move failed.
public func runTrashHelper(arguments: [String], realHome: String,
                           trash: (URL) throws -> Void) -> (code: Int32, message: String)
```

- **Rules for `checkTrashable`:**
  - `home` and `path` are absolute, with no `.`, `..` or empty components.
  - `path` is inside `home`. The relative form is one of these, and nothing else:
    - `Downloads/<name>` or `Downloads/<dir>/<name>`. The target is `lstat` S_IFREG.
    - `Library/Developer/Xcode/Archives/<date>/<name>.xcarchive`. The target is `lstat` S_IFDIR.
  - Every intermediate component below `home` is `lstat` S_IFDIR and not a symlink.
- **`runTrashHelper`:**
  - Parses `--home H PATH`; anything else gives exit 2.
  - Resolves `H` with `realpath`.
  - If `H == realHome`, it calls `trash(url)`.
  - Otherwise it moves the item into `H/.Trash`, creating that folder at 0700. On a name clash it uses `name 2`, `name 3` and so on. It never overwrites.
- **`main.swift`** passes `realHome` as the resolved `getpwuid(getuid()).pw_dir`, and `trash` as `FileManager.default.trashItem(at:resultingItemURL:)`. The real trash closure is never used in tests.

public struct ServerHandshake: Equatable { public let url: URL; public let port: Int }
/// nil unless: JSON object, labyrinth_server == 1, url scheme http, host 127.0.0.1, port set, non-empty `t` query.
public func parseHandshake(_ line: String) -> ServerHandshake?

/// PATH = /opt/homebrew/bin:/usr/local/bin:<home>/.docker/bin:<home>/.orbstack/bin:
///        /Applications/Docker.app/Contents/Resources/bin:/usr/bin:/bin:/usr/sbin:/sbin
/// Drops every PYTHON* key. Sets HOME=home, LABYRINTH_TRASH_HELPER=helperPath.
public func serverEnvironment(base: [String: String], home: String, helperPath: String) -> [String: String]

public struct ServerLaunch { public var python, script: String; public var arguments: [String] }
/// [python, "-E", "-s", "-X", "utf8", script, "ui", "--app"] + fixture args
public func serverLaunch(resources: URL, fixture: FixtureOptions?) -> ServerLaunch
public struct FixtureOptions: Equatable { public var home: String; public var simctl: String?; public var fakeDocker: String? }
/// nil without --fixture-home; --simctl-fixture / --fake-docker without --fixture-home -> nil; values must be absolute.
public func parseFixtureOptions(_ args: [String]) -> FixtureOptions?

public enum ServerFailure: Error { case noHandshake(stderrTail: String), exited(status: Int32, stderrTail: String) }
public final class ServerProcess {
    public init(launch: ServerLaunch, environment: [String: String], handshakeTimeout: TimeInterval = 30)
    /// Starts once; later calls while running return the same handshake (no second process).
    public func start(completion: @escaping (Result<ServerHandshake, ServerFailure>) -> Void)
    public var onUnexpectedExit: ((ServerFailure) -> Void)?
    /// Closes stdin, sends SIGTERM, waits up to `grace` s, then SIGKILL. Calls completion on main.
    public func stop(grace: TimeInterval = 30, completion: @escaping () -> Void)
}
public func legacyBarRunning(bundleIDs: [String]) -> Bool   // true if "local.devclean.bar" is among them
```
